Digital Color Systems and Quantization

Chromius

Digital displays recreate the real world by translating continuous light into numerical Red, Green, and Blue (RGB) values. Explore how color quantization reduces these colors to save file space without sacrificing image quality.

The RGB Model

Screens do not use physical ink; they produce color through additive mixing of light using clusters of microscopic Red, Green, and Blue (RGB) sub-pixel LEDs. By adjusting the intensity of each primary light channel from full darkness to full brightness, a screen can reproduce practically any color.

To control these light intensities electronically, the computer must convert them into numbers.

Storing Colors as Numbers

In modern digital media, full-color images use 24-bit color depth. Each pixel allocates 3 bytes (24 bits)—one dedicated byte (8 bits) to each RGB channel.

While 16.7 million colors look smooth and lifelike, light in nature is infinite and unbroken. Turning continuous light into numbers requires two distinct steps: sampling and quantization.

Digitization Concepts

The process of converting continuous light into digital numbers involves two key steps: sampling and quantization.

Sampling

Divides continuous space into a grid of discrete pixels (e.g., 1920 × 1080 screen resolution). It answers the question, "Where and how often do we measure?"

Quantization

Maps infinite, continuous light values into a finite set of allowed digital numbers (0-255). It answers the question, "What fixed value do we round each color to?"

Storing 24 bits for every pixel creates large files. To save bandwidth and storage, we use color quantization to compress the color data.

Compression via Quantization

Color quantization reduces an image's palette from millions of colors down to a compact set while keeping it visually recognizable, by grouping nearby shades into clusters and picking one representative color for each.

While this dramatically cuts file size, rounding colors to a smaller palette has visual consequences.

Quantization Artifacts

When there are not enough discrete color levels to recreate subtle tone shifts, smooth transitions collapse into visible, step-like stripes known as color banding.
